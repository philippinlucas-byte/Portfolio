# Instructions de génération pour le Portfolio

Tu dois concevoir un site web portfolio de graphiste professionnel, haut de gamme et moderne, en t'aidant du skill de design Impeccable pour structurer le code et l'UI sans tomber dans les pièges de l'AI slop (pas de dégradés violet-néon génériques, pas de structures vues et revues).

## Sources et Contenu
- Reprends exactement la même structure, les mêmes textes et les mêmes images que ceux situés dans le dossier `/contenu` (regarde le fichier `sitemap.xml` et les sous-dossiers correspondants pour chaque page).

## Charte Graphique & Typographie
- Conserve une charte graphique soignée, épurée et professionnelle adaptée à un portfolio de graphiste.
- Base toi sur les éléments de ma charte conservés dans le dossier `/charte` 
- **Polices obligatoires :** 
  - Titres : **Glook**
  - Corps de texte : **Geist**
- Intègre des effets d'animation modernes et fluides au défilement (fade-in, transitions douces) pour valoriser le travail visuel, mais de manière subtile et performante.

## Stack Technique
- Tu es libre de choisir la stack technique la plus fiable et la plus adaptée (ex: HTML/CSS/JS natif, ou un générateur statique léger comme Astro/Vite si pertinent pour le déploiement sur Cloudflare Pages). Le code doit être propre, modulaire et prêt à être compilé.
